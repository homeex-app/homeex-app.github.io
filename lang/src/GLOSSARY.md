# Translation glossary (Home Ex)

Source: Arabic descriptions in Firestore `exercises`. Every language file in this folder
(`en.txt`, `es.txt`, ...) has one block per exercise:

```
@<exercise number>
<exercise name>
<description, can be several lines>
```

`python tools/build_lang.py` turns them into `lang/<code>.json` (keyed by Firestore id).
Write to the patient directly ("Lie on your back"), simple words, same term every time.
